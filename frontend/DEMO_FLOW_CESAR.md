# Flujo visual recomendado para la demo

1. Dashboard: estado normal y origen del dato.
2. Lab: seleccionar escenario claramente etiquetado como integrado o simulación controlada.
3. Incidents: mostrar severidad y evidencia.
4. Incident Detail: explicar MITRE como clasificación contextual.
5. Actions: mostrar decisión/acción y su estado real (pending/executed/etc.).
6. Protections: cerrar mostrando cobertura de los controles y cuáles siguen pendientes.

Regla narrativa: señal → clasificación → incidente → acción → evidencia → estado final.
